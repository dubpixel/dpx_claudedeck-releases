# dpx_claudeDeck

**one button, one project, one Space away**

A macOS menu-bar app that turns an Elgato Stream Deck into a live window
switcher for your open VS Code, Terminal, KiCad, and Fusion 360 projects.

### [⬇ Download the latest release](https://github.com/dubpixel/dpx_claudedeck-releases/releases/latest)

macOS (Apple Silicon) · free · unsigned build

### [📖 Read the manual](https://dubpixel.github.io/dpx_claudedeck/)

</div>

## What it does

If you keep half a dozen VS Code windows and Terminal tabs open across
different macOS Spaces — one per project — dpx_claudeDeck gives each one
its own physical button. Tap it, and macOS jumps straight to that
project's Space with the window focused and ready to type. Buttons
auto-populate from whatever windows are actually open — no manual
per-project setup.

It talks directly to the Stream Deck over USB — no Elgato Stream Deck
software, no Bitfocus Companion required.

## Requirements

- macOS Sonoma or later, Apple Silicon
- An Elgato Stream Deck
- Accessibility permission (Screen Recording too, if you enable thumbnails)

## Install

1. [Download the latest release](https://github.com/dubpixel/dpx_claudedeck-releases/releases/latest) and unzip it.
2. Drag `dpx_claudeDeck.app` into `/Applications`.
3. Right-click the app → **Open** the first time (it's unsigned — this is a one-time step).
4. Grant Accessibility / Screen Recording when prompted.

Full walkthrough, features, and settings guide: **[the manual](https://dubpixel.github.io/dpx_claudedeck/)**.
