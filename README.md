# dpx_claudeDeck — Releases

Packaged macOS builds of [dpx_claudeDeck](https://github.com/dubpixel/dpx_claudedeck),
a menu-bar app that turns an Elgato Stream Deck into a live window switcher.

Source code is private — this repo exists only to host public download links
for compiled builds. See the [manual](https://dubpixel.github.io/dpx_claudedeck/)
for setup and usage.

**Latest release:** see the [Releases page](https://github.com/dubpixel/dpx_claudedeck-releases/releases/latest).
